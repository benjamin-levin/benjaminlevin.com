# Deployment

The portfolio uses an isolated Docker Compose project for its web app and an optional Cloudflare tunnel. Keep local work and the live deployment in separate Compose projects.

## Build and run the web app

```sh
docker compose --project-name blevin-local -f docker-compose.yml up -d --build web
```

The default web port is 3003. Existing deployment-specific overrides may change mounts or other settings; retain the exact file set and named volumes used by that deployment.

## Existing live deployment

Create `.env.docker` from the empty `.env.docker.example` template and configure the tunnel through the normal operator workflow. The environment file and any local `docker-compose.override.yml` stay ignored.

For an existing deployment that uses base, override, and deploy files:

```sh
docker compose --project-name blevin-live --env-file .env.docker \
  -f docker-compose.yml -f docker-compose.override.yml -f docker-compose.deploy.yml \
  build web

docker compose --project-name blevin-live --env-file .env.docker \
  -f docker-compose.yml -f docker-compose.override.yml -f docker-compose.deploy.yml \
  up -d --no-deps --no-build --pull never --wait --wait-timeout 60 web
```

The override is local configuration, not a file provided by the public repository. A deployment without one uses its established base/deploy file set. Do not introduce or remove configuration files merely to match an example.

This web-only update preserves the existing tunnel and other services. Keep a prior web-image tag and source backup when publishing changes. Never remove or replace the runtime data/authentication volumes during a content update.

## Verify

Check the local origin, public homepage, changed case-study routes, section links, and `/api/chat/health`. A successful source build alone does not establish that public content changed.

The assistant context is generated by `node scripts/build-context.mjs` and baked into the image. Authentication stays in the deployment's existing private volume or mount. This repository contains a profile template, not authentication material.
